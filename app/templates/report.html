Annahmen zu dieser Auswertung

Grundlage der Bewertung sind die im Fragenkatalog erfassten Selbstauskünfte ({{ answered_count }} von {{ total_count }} Fragen beantwortet). Eine Stufe gilt als erreicht, wenn alle ihr zugeordneten Themengebiete im Durchschnitt mindestens {{ level_threshold }} % erzielen – und alle darunterliegenden Stufen ebenfalls erfüllt sind. Für {{ next_level.full_name }} sind das aktuell {{ customer_recs_count }} Punkt{{ 'e' if customer_recs_count != 1 else '' }} mit klarem Nachholbedarf („Trifft nicht zu“) {% if next_level_partial_count > 0 %} sowie {{ next_level_partial_count }} weitere, bereits teilweise erfüllte Punkte, die mit vergleichsweise geringem Aufwand nachgeschärft werden können {% endif %}. Diese Einschätzung basiert auf einer Selbsteinschätzung und ersetzt keine vertiefte Vor-Ort-Analyse, bildet aber eine belastbare Grundlage für die Priorisierung der nächsten Schritte.
